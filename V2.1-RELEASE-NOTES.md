# NutriTrack V2.1 – Smart Nutrition Update

## Included in this package
- Edit a diary entry quantity and meal category; macro/calorie values scale with the quantity.
- Copy a logged food entry to another date.
- Choose the meal category when reusing a saved meal.
- Online barcode lookup using the Open Food Facts public API; all returned values must be checked before saving. Manual product entry remains available offline.
- Light/dark appearance toggle with saved preference.
- Android app version updated to 2.1.0 (versionCode 3).

## Important limitations
- This package does **not** yet contain an offline OCR engine or reliable Arabic nutrition-label OCR. Product photos can be selected and saved, but nutrition values still require manual verification and entry.
- Barcode lookup requires an internet connection and a product record in Open Food Facts. It is not a camera barcode scanner.
- The JavaScript was syntax-checked, but an Android APK build has not been run in this environment. Run the repository GitHub Actions workflow and test the resulting APK on-device before relying on it.
